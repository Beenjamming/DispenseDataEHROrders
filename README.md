# Dispense Data EHR Orders (Supplemental)

Supplemental repository illustrating a pragmatic linkage strategy between **EMR medication orders** and **outside pharmacy dispense history**.

This repository is intended as an **illustrative outline** of the analytic framework. It includes a small **executable, synthetic-data demo notebook** and its generated example outputs so readers can inspect the workflow end-to-end.

## Files
- PseudoSQL.sql — documentation-only pseudo-SQL sketch of join strategy and fallback options
- ERD.drawio — entity relationship diagram notes
- SampleMedicationDataLoad.ipynb — executable synthetic-data demo that generates the example outputs below
- matched_records.csv — example matched output generated by the notebook
- medication_data.db — SQLite database generated by the notebook (simulated source + derived tables)

## Purpose
Demonstrates a pragmatic matching strategy:
- Prefer direct `Order_ID` matches when present in both sources.
- Fallback to composite matching using patient demographics, medication identifier, and normalized pharmacy identifiers.

## Data availability / reproducibility notes
- The notebook uses **synthetic data** and can be run locally to regenerate `matched_records.csv` and `medication_data.db`.
- The committed `matched_records.csv` and `medication_data.db` are provided as **worked example outputs** to support transparency of the linkage framework.
